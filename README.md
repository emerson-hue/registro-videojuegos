## Descripción
Esta es una aplicación de consola en Java que sirve para llevar un registro de videojuegos. Utiliza la estructura de Records para definir los datos de cada juego (título, plataforma y precio) y un arreglo tradicional para guardar la información mientras el programa está en uso, sin necesidad de bases de datos.

## Instrucciones de ejecución
Al iniciar el programa, aparecerá un menú numérico en la pantalla. Para interactuar con la aplicación, debes escribir el número de la opción deseada y presionar Enter:

* Opción 1: El sistema te pedirá ingresar los datos (título, plataforma y precio) para registrar un nuevo videojuego en el catálogo.
* Opción 2: El sistema te mostrará en pantalla la lista completa de los videojuegos que has registrado hasta el momento.
* Opción 3: Finaliza y cierra el programa.
